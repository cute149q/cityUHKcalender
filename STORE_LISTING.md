# Chrome Web Store listing draft

## Name

CityUHK Calendar

## Short description

Export your CityUHK AIMS detail schedule as an iCalendar file in one click.

## Description

Open your CityUHK AIMS Student Detail Schedule, then click CityUHK Calendar. Review the classes found, choose an optional reminder, and download a calendar file for Apple Calendar, Google Calendar, Outlook, and other calendar apps.

Your timetable is read and converted locally in your browser. No AIMS password, cookie, or timetable data is sent to any server.

## Privacy-practices answers

- Single purpose: convert the user's open CityUHK AIMS detail schedule into an iCalendar file.
- `activeTab`: access only the current AIMS tab after the user opens the extension.
- `scripting`: read the schedule table from the current AIMS tab when the user asks to export it.
- `downloads`: save the generated iCalendar file to the user's device.
- `storage`: retain only the user's selected interface language locally.
- Remote code: none.
- Data collection: none. Timetable content is processed locally and is never transmitted.
